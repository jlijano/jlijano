# Architecture Decision Records (ADRs)

Write one numbered Markdown document per material design decision: `0001-short-decision-title.md`.

## Template

# ADR NNNN — Decision title
- Status: proposed | accepted | superseded
- Date:
- Decision owner:

## Context
What business problem, constraints, risks, and existing architecture drive this choice?

## Options considered
List realistic options and trade-offs, including doing nothing.

## Decision
Describe the chosen approach and why it is proportionate.

## Consequences
Expected benefits, costs, security/privacy impact, migration, operational effects, and rollback.

## Validation
Acceptance criteria, measurements, tests, and follow-up actions.
